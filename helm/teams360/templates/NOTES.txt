Thank you for installing {{ .Chart.Name }}!

To check the status of the deployment:
  kubectl get pods -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ include "teams360.namespace" . }}

To view the API logs:
  kubectl logs -l app=teams360-api -n {{ include "teams360.namespace" . }} -f

To view the frontend logs:
  kubectl logs -l app=teams360-frontend -n {{ include "teams360.namespace" . }} -f

To view the PostgreSQL logs:
  kubectl logs -l app=teams360-postgres -n {{ include "teams360.namespace" . }} -f
